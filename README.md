# Pustaka Booking

Aplikasi web peminjaman dan booking buku perpustakaan yang dibuat berdasarkan modul materi Web Programming II Universitas Bina Sarana Informatika, menggunakan framework CodeIgniter 3.

## Fitur

- Login admin dan siswa (member).
- Admin: kelola buku, siswa, peminjaman, booking, dan laporan.
- Siswa: booking dan peminjaman buku.

## Tech stack

- PHP, CodeIgniter 3
- MySQL

## Menjalankan

1. Import database, lalu sesuaikan konfigurasi di `application/config/database.php`.
2. Sajikan lewat server PHP (XAMPP/Laragon).
3. Login admin: `admin@anrdart.com` / `alul`, dashboard di `http://localhost/pustaka-booking/admin`.
